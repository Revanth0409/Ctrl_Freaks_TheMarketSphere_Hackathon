# Ctrl_Freaks_TheMarketSphere_Hackathon
The attached file dashboard.html contains the simulation of the first 60 minutes after the market crashes.
The different menu's contain different functions and how users can see updates from the company of the status of the crash and the users can raise an issue through which they can mention what losses they have incurred which can be noted by the crisis officer and the status can also be reviewed by the user using a case id
